# Security policy

The supported release is the current 0.1 alpha. This is an early remediation-evidence
tool, not an exploit blocker or a compromise-clearance certificate.

Report vulnerabilities through this repository's private vulnerability reporting
feature when available. Public issues should contain only sanitized, non-sensitive
reproductions. Never attach credentials, raw production reports or customer data.

Threat boundaries and known limitations are documented in [the evidence model](docs/EVIDENCE.md).
